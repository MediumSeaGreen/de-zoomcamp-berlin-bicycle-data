# Evidence Folder

This folder contains the implementation of the visualization layer for the Berlin Bicycle Data Pipeline project. It uses [Evidence](https://evidence.dev), a modern visualization framework, to create interactive dashboards and reports based on the processed data.

## Key Components
- pages/: Contains the Markdown pages for the visualizations, including charts and interactive elements.
- sources/: Includes SQL queries and configurations for connecting to the BigQuery data source.

The visualizations showcase trends and patterns in Berlin's cycling activity, leveraging data transformed into a star schema by dbt.
