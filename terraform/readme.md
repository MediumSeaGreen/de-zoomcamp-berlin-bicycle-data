# Terraform Folder Structure

This folder contains the Terraform configuration files for managing the infrastructure of the project. Below is an overview of the structure:

- variables.tf: Defines input variables for the Terraform configuration.
- bucket.tf: Configures a Google Cloud Storage bucket for the project.
- bigquery.tf: Sets up BigQuery datasets and tables.
- .env_template: Template for environment variables required by Terraform.

Ensure to set the environment variables before applying the configuration.
